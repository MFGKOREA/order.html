# Astro Adventure

한글 제목은 아직 정하지 않았어요.

[English](README.md)

브라우저에서 바로 실행되는 세로형 맵 이동 서바이벌 게임 프로토타입입니다. `index.html` 파일 하나로 되어 있어요.

## 규칙
- 화면 가로 2장, 세로 2장 크기의 맵을 돌아다녀요. 피해 다닐 수 있는 달 바위가 몇 개 있어요. 외계 벌레가 사방에서 나타나 대장을 쫓아와요.
- **대장과 부대**: 출전 칸에서 등급이 가장 높은 친구가 대장이 되고, 나머지는 줄줄이 따라와요. 대장만 맞아요. 닿으면 체력이 깎이고 잠깐 깜빡이며 무적이 돼요. 대장 체력이 0이 되면 패배해요.
- **라운드**: 한 라운드는 30초, 총 30라운드예요. 시간이 끝나면 남은 벌레는 사라지고, 바닥의 보석은 자동으로 모이고, 대장 체력이 최대치의 30% 회복돼요.
- **정비 화면** (라운드 사이): 코인으로 친구를 랜덤 뽑기하고, 출전 6칸과 대기소 12칸 사이로 끌어 옮기고, 같은 종류·등급 2마리를 겹쳐 합성하고, 필요 없는 친구는 판매한 뒤 GO를 눌러요.
  - 등급 확률: 일반 72% · 희귀 22% · 영웅 5.5% · 전설 0.5%. 뽑을 때마다 가격이 2씩 올라요.
- **포위 웨이브**: 5라운드부터 한 라운드에 두 번, 벌레가 원을 그리며 조여와요. 빈틈으로 빠져나가세요.
- **보스**: 10·20라운드 중간 보스, 30라운드 최종 보스. 최종 보스를 30초 안에 잡으면 승리해요. 보스가 화면 밖에 있으면 가장자리 화살표가 방향을 알려줘요.
- **레벨 업 카드**: 적을 잡으면 경험치 보석이 떨어져요. 가까이 가면 주워져요('강력 자석' 카드로 범위가 넓어져요). 경험치 바가 차면 카드 3장 중 1장을 골라요. 추천 카드 표시가 있고, 한 판에 리롤 3번을 쓸 수 있어요.
- **업그레이드**: 한 판이 끝나면 골드를 받아요. 타이틀이나 결과 화면에서 공격력, 대장 체력, 장갑, 시작 코인, 행운 뽑기, 빠른 성장을 영구 강화해요. 진행 상황은 이 브라우저에 저장돼요.

## 유닛
유닛은 아스트로 프렌즈예요. 칸 모서리 배지로 역할을 구분해요.

| 이름 | 동물 | 역할 |
|---|---|---|
| 치즈 | 고양이 | 소총: 앞쪽 적을 빠르게 사격 |
| 솜이 | 토끼 | 저격: 가장 긴 사거리, 체력이 가장 높은 적을 노림 |
| 단풍 | 여우 | 화염: 짧은 사거리 범위 피해 |
| 밤톨 | 곰 | 포격: 포탄 범위 피해 |
| 콩떡 | 판다 | 냉기: 맞은 적을 느리게 만듦 |
| 찌릿 | 햄스터 | 전기: 여러 적에게 번개가 튐 |

5마리는 캐릭터 시트에서 잘라 넣었고, 찌릿은 정식 그림이 나올 때까지 코드로 그린 임시 그림이에요.

사거리는 친구를 중심으로 한 공격 반경이에요. 단풍(화염)이 가장 짧고 솜이(저격)가 가장 길어요.

## 조작
- 전투: 맵 아무 곳이나 누른 채 끌면 대장이 그 방향으로 움직여요(가상 조이스틱). 방향키나 WASD도 돼요.
- 정비 화면: 친구를 끌어 옮기기·합성·판매, 탭하면 정보 보기
- 키보드: 정비 화면에서 Space 뽑기, Enter GO, Esc/P 일시정지, 1/2/3 레벨 업 카드 선택
- 화면 오른쪽 위 `EN`/`한` 버튼으로 영어·한국어 전환 (기본은 영어)

## 밸런스 메모
영구 업그레이드 없이, 가까운 벌레를 피해 다니고 무조건 합성한 뒤 가장 좋은 6마리를 출전시키고 추천 카드를 고르는 봇으로 5판 돌려 보면 2판 승리했어요. 5판 모두 30라운드 최종 보스까지 갔어요. 사람은 봇보다 덜 피하니 중반이 더 어렵게 느껴질 수 있어요.
수치는 `index.html` 위쪽 `TYPES`, `GRADES`, `MON`, `BOSS_HP`, `hpBase`, `drawCost`, `CARDS`, `META`와 맵·이동 상수(`WORLD_W`, `LEADER_SPD`, `PICK_R`)에서 조정해요.
