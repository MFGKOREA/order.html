# Astro Adventure

한글 제목은 아직 정하지 않았어요.

[English](README.md)

브라우저에서 바로 실행되는 세로형 웨이브 디펜스 게임 프로토타입입니다. `index.html` 파일 하나로 되어 있어요.

## 규칙
- 왼쪽이 우리 진영(아스트로 프렌즈 18칸), 오른쪽에서 외계 벌레가 몰려와요.
- **유닛 뽑기**: 코인으로 6종 유닛 중 하나를 랜덤으로 뽑아요. 뽑을 때마다 가격이 2씩 올라요.
  - 등급 확률: 일반 72% · 희귀 22% · 영웅 5.5% · 전설 0.5%
- **합성**: 같은 종류·같은 등급 유닛을 끌어다 겹치면 다음 등급이 돼요.
- **판매**: 유닛을 왼쪽 아래 판매 칸으로 끌어다 놓으면 코인을 돌려받아요.
- **라운드**: 30초마다 다음 라운드로 넘어가요. 총 30라운드예요.
- **보스**: 10·20라운드에는 중간 보스, 30라운드에는 최종 보스가 나와요. 최종 보스를 30초 안에 잡으면 승리해요.
- 적이 방벽을 공격해서 방벽 체력이 0이 되면 패배해요.
- **레벨 업 카드**: 적을 잡으면 경험치 보석이 떨어져요. 경험치 바가 차면 카드 3장 중 1장을 골라요(전체 공격력, 공격 속도, 치명타, 유닛별 특훈 등). 지금 덱에 맞는 카드에는 추천 표시가 붙고, 한 판에 리롤 3번을 쓸 수 있어요.
- **전설 연출**: 전설 유닛을 뽑거나 합성하면 전체 화면 등장 연출이 나와요.
- **업그레이드**: 한 판이 끝나면 골드를 받아요(라운드가 높을수록, 이기면 더 많이). 타이틀이나 결과 화면에서 공격력, 방벽 체력, 장갑, 시작 코인, 행운 뽑기, 빠른 성장을 영구 강화해요. 진행 상황은 이 브라우저에 저장돼요.

## 유닛
유닛은 아스트로 프렌즈예요. 칸 모서리 배지로 역할을 구분해요.

| 이름 | 동물 | 역할 |
|---|---|---|
| 치즈 | 고양이 | 소총: 앞쪽 적을 빠르게 사격 |
| 솜이 | 토끼 | 저격: 맵 전체 사거리, 체력이 가장 높은 적을 노림 |
| 단풍 | 여우 | 화염: 짧은 사거리 범위 피해 (방벽 쪽 추천) |
| 밤톨 | 곰 | 포격: 포탄 범위 피해 |
| 콩떡 | 판다 | 냉기: 맞은 적을 느리게 만듦 |
| 찌릿 | 햄스터 | 전기: 여러 적에게 번개가 튐 |

5마리는 캐릭터 시트에서 잘라 넣었고, 찌릿은 정식 그림이 나올 때까지 코드로 그린 임시 그림이에요.

사거리는 유닛 위치에서 오른쪽으로 닿는 거리라서, 사거리가 짧은 유닛은 방벽 가까운 칸(오른쪽 열)에 두는 게 좋아요.

## 조작
- 터치/마우스: 뽑기 버튼, 유닛 드래그(이동·합성·판매), 유닛 탭(정보·사거리 보기)
- 키보드: Space/Enter 뽑기, Esc/P 일시정지, 1/2/3 레벨 업 카드 선택
- 화면 오른쪽 위 `EN`/`한` 버튼으로 영어·한국어 전환 (기본은 영어)

## 밸런스 메모
영구 업그레이드 없이, 자동 봇(무조건 합성 → 남는 코인으로 뽑기 → 추천 카드 선택, 배치 전략 없음)으로 8판 돌려 보면 3판 승리, 나머지는 29~30라운드에서 패배해요. 사거리에 맞춰 배치하고 업그레이드를 사면 더 유리해요.
수치는 `index.html` 위쪽 `TYPES`, `GRADES`, `MON`, `BOSS_HP`, `hpBase`, `drawCost`, `CARDS`, `META`에서 조정해요.
