## 3. 어사이드 기능 (조사 11.28, **공식 문서가 아닌 글 2개 기준 → 설치 뒤 확인**)

| 기능 | 글에 적힌 것 | 이 계획에서 쓸 곳 |
|---|---|---|
| 모델 연결 | 설정 > Models 의 Subscription 에 Claude Pro/Max 연결 → 어사이드 크레딧 안 씀 | C |
| Routines | 정해진 시각에 새 일을 시작(Cron) / 있던 대화를 깨워 잇기(Heartbeat). 설정 > Routines. 무료 3개, Pro 무제한 | 2~7번 정기 조회, 허브 `tasks/` 몇 분마다 확인 |
| 명령줄(CLI) | `aside "할 일"` · `aside exec` (스스로 하는 일) · `aside repl` (정해진 코드로 화면 읽기) | 클로드·그록 봇이 터미널에서 바로 명령 |
| MCP | `aside mcp` — 클로드 코드가 어사이드를 도구로 씀 | 매장 PC 클로드 코드 → 어사이드 |
| 원격 | `aside host list` · `aside exec --host <기기>` — 다른 기기에서 매장 PC 어사이드에 명령. 로그인·쿠키는 매장 PC에 남음 | **실시간 명령** (집 PC 그록 봇·클로드 → 매장 PC) |
| 암호 | 에이전트는 비밀번호 값을 못 봄(Vault 가 채움) | D |

- 출처: https://daleseo.com/aside/ (11.7 고침) · https://mcpmarket.com/tools/skills/aside-browser-automation (본 날 11.28)
- **모름:** `aside repl` 이 로그인된 화면을 볼 수 있는지(글에는 "항상 시크릿 모드"라고 적힘). 되면 숫자를 AI가 옮겨 적지 않고 코드로 읽을 수 있어 틀릴 일이 줄어듭니다.

## 4. 결과를 시트에 넣는 길 (A — 새로 만들 것 없음)

발주 시트 주소(Apps Script)는 지금도 `{ action: "set" | "merge", key, value }` 를 받습니다(label-list `apps-script/order/Code.gs` 의 `doPost`). GW Agent 가 쓰는 그 길입니다.
- 어사이드는 **같은 주소에 다른 키**로 씁니다: `misRecv` 대신 `asideRecv` 처럼. 병행하는 동안 GW Agent 값을 덮어쓰지 않습니다.
- 맞춰 보기는 클로드 코드가 코드로 합니다(두 키를 날짜별로 비교 → 허브에는 "같음/다름 N건"만).
- 통과하면 어사이드가 원래 키(`misRecv`)에 쓰도록 바꿉니다.
- 주소는 이 허브에 적지 않습니다(label-list 발주앱에 있는 주소를 씀).
