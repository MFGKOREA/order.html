## 3. 옮기는 순서

| 단계 | 무엇 | GW Agent | 통과 기준 |
|---|---|---|---|
| 0 | **설치 · 기능 확인** ([`runbook`](runbook-store-pc.md) 1~8번) | 그대로 | 기능 시험 1번(코드 실행) 또는 3번(북마크)이 됨 · GW 진입 됨 · 동시 로그인 됨 |
| 1 | **섀도: 입고현황** 1주 (매일 10:40) | 그대로 | 7일 중 6일 넘게 끝까지 돎 · 다름 0 (또는 까닭이 설명됨) |
| 2 | **섀도: 하루 한 번 읽기 전부** 1주 (주문·재고이동·세트·메뉴·Gross) | 그대로 | 위와 같음 |
| 3 | **섀도: 오늘 값 · 라인체크** 1주 (16:10) | 그대로 | 끝까지 돎 · 모양 맞음 · 알림이 두 번 가지 않음 |
| 4 | **남은 것 만들기**: 마감 기록 · 근태 읽기 · 근태 보내기 (1번 표의 12~14) | 그대로 | 가짜 화면 시험 통과 + 근태는 KM 결정 |
| 5 | **발주 연습**: KM 이 보는 앞에서 어사이드 브라우저로 하루 발주를 넣어 봄 (확인 창이 뜨는 방식) | 그대로 (그날 전송은 어사이드로) | 줄 수·수량이 앱과 같음 |
| 6 | **넘기는 날**: GW Agent 확장을 끄고 `asideCfg` 를 실제로 (읽기 + 발주 같이) | **끔** (지우지 않음) | 2주: Gross 정오 전 도착이 기준선(36%)보다 높음 · 폰 전송 무사고 |
| 7 | GW Agent 지우기 | 지움 | 6단계 뒤 1달 무사고 |

- 읽기와 발주는 **같은 날** 넘깁니다. GW Agent 가 켜져 있으면 요청을 가리지 않고 다 받기 때문에, 반만 넘길 수 없습니다(확장을 고치면 되지만 다시 설치해야 함).
- 4단계가 끝나기 전에는 6단계로 못 갑니다. 확장을 끄면 근태·마감 기록도 같이 멈춥니다.
- 1~3단계는 GW Agent 를 건드리지 않으므로 **지금 바로** 시작할 수 있습니다.

## 4. 되돌리는 법

| 때 | 되돌리기 |
|---|---|
| 섀도 중 (1~3단계) | 책상 [설정] → 이 PC 한도 "보기만". GW Agent 는 처음부터 그대로라 돌릴 것이 없음 |

| 발주 시간(12:30~14:45)에 어사이드가 못 받음 | 폰에 "MIS에 직접 넣어 주세요"가 6분 안에 뜸 → 직접 넣거나 확장을 켬 |
