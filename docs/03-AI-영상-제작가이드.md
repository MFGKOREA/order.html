# 얼굴 없는 쇼츠 영상 제작 가이드 (AI 활용)

세 가지 방법 중 상황에 맞게 고릅니다. **비용 0원 → 유료 AI** 순서입니다.

| 방법 | 비용 | 소요 | 이럴 때 |
|---|---|---|---|
| A. 숏핑 스튜디오에서 바로 녹화 | 무료 | 영상 길이만큼 | 사진만 있고 빠르게 많이 만들 때 |
| B. CapCut 편집 | 무료(일부 유료) | 10~20분 | 직접 찍은 손 컷, 효과음, 전환 효과를 넣고 싶을 때 |
| C. AI 이미지→영상 + 편집 | 크레딧 소모 | 20~30분 | 상품을 직접 못 찍었지만 움직이는 장면이 필요할 때 |

---

## A. 숏핑 스튜디오에서 바로 녹화
1. `index.html`을 크롬/엣지에서 연다 (파일을 더블클릭하거나 GitHub Pages로 배포)
2. 상품 정보 입력 → **대본·자막** 탭에서 훅 고르고 문장 다듬기
3. **영상 만들기** 탭 → 상품 사진 여러 장 올리기 (장면 순서대로 돌아가며 들어감)
4. (선택) TTS 음성 파일 올리기 → 대본 길이와 1.5초 이상 차이 나면 경고가 뜸
5. **영상 녹화하기** → 끝나면 **영상 내려받기** (크롬 최신 버전은 MP4, 아니면 WebM. 유튜브는 둘 다 됨)

화면 상단 광고 배지, 진행 바, 가격 카드, 장면별 자막이 자동으로 들어갑니다.
빨간 점선은 쇼츠 UI에 가려지는 영역 표시이며 녹화에는 들어가지 않습니다.

## B. CapCut으로 편집 (권장 품질)
1. 숏핑 스튜디오에서 **SRT 내려받기**
2. 내레이션을 TTS로 만들기: CapCut의 텍스트 음성 변환에 대본 복사 → 한국어 음성 선택 → 속도 1.1~1.2배
3. CapCut 새 프로젝트(9:16) → 영상 컷 배치 → 음성 넣기 → **캡션 → 파일 가져오기(SRT)**
4. 자막 스타일: 굵은 고딕, 흰 글자 + 검은 테두리, 화면 중앙보다 약간 위
5. **영상 처음과 끝에 광고 표기 텍스트** 넣기 (전체 구간에 두는 것이 가장 안전)
6. 1080×1920, 30fps로 내보내기

## C. AI 이미지→영상 (Higgsfield · Kling · Veo 등)
상품 사진을 **시작 프레임**으로 넣고, 장면별 프롬프트로 3~5초짜리 컷을 만든 뒤 B 방법으로 이어 붙입니다.
숏핑 스튜디오 **AI 프롬프트** 탭이 장면마다 영어 프롬프트를 만들어 줍니다.

### 프롬프트 기본형
```
Vertical 9:16, photorealistic product video, start frame = uploaded product photo.
[장면 설명]
Keep the product shape, color and logo exactly as in the photo.
No added text, no watermarks, no human faces.
```

### 장면별 예시 (접이식 설거지통)
| 장면 | 프롬프트 핵심 |
|---|---|
| 훅 | Fast dynamic push-in on a collapsible gray silicone dish basin, it pops into sharp focus, bright clean lighting |
| 등장 | Hero shot on a clean kitchen counter, slow 180-degree orbit, soft daylight |
| 포인트 | Macro close-up, hands fold the basin flat, smooth slow motion |
| 가격 | Product centered on a solid bright yellow background, playful bounce |
| 마무리 | Final wide shot in a tidy real kitchen, gentle slow push-in, warm light |

### 주의
- AI가 상품 모양·로고를 바꾸면 **허위 표시**가 될 수 있습니다. 실제 상품과 다른 컷은 쓰지 마세요.
- 사람처럼 보이는 손·얼굴, 실제 장소처럼 보이는 장면이 사실적으로 나오면 업로드 시 **변경되거나 합성된 콘텐츠**를 '예'로 표시하세요.
- 크레딧 비용이 들기 때문에, 먼저 A 방법으로 반응을 보고 **반응 좋은 상품만** AI 컷을 추가하는 순서를 추천합니다.

## 이미지 사용 원칙
| 소재 | 사용 |
|---|---|
| 직접 산 상품을 직접 찍은 사진·영상 | 가장 안전, 가장 반응 좋음 |
| 쿠팡 파트너스가 제공하는 상품 이미지 | 파트너스 이용 약관 범위 안에서 |
| 판매 상세페이지 이미지·영상 캡처 | 판매자 저작물. 허락 없이 쓰지 않기 |
| 다른 유튜버·틱톡 영상 | 사용 금지 |
| 무료 스톡(Pexels, Pixabay 등) | 공감 장면(지저분한 싱크대 등)에 활용 가능, 각 사이트 라이선스 확인 |

## TTS 음성 고르기
- 20~30대 여성/남성 밝은 톤, 속도 1.1~1.2배
- 채널 전체에서 **같은 목소리**를 계속 써야 채널 정체성이 생김
- 상업적 이용이 허용되는 TTS인지 약관 확인
