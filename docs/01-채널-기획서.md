# 유튜브 쿠팡 쇼핑 숏폼 채널 기획서

> 얼굴 없이(Faceless) 상품 영상 + 자막 + AI 내레이션으로 운영하는 쇼츠 채널.
> 수익은 **쿠팡 파트너스 / 유튜브 쇼핑 제휴 수수료**가 중심이고, 채널이 자라면 유튜브 광고 수익이 더해진다.

---

## 1. 채널 콘셉트

| 항목 | 내용 |
|---|---|
| 한 줄 정의 | "자취·살림의 작은 불편을 만 원대로 해결하는 물건을 30초 안에 보여주는 채널" |
| 시청자 | 20~30대 1인 가구, 신혼부부, 살림 효율을 중시하는 사람 |
| 약속(Value) | ① 30초 안에 핵심만 ② 가격·할인 바로 공개 ③ 과장 없이 “어디에 좋은지”만 |
| 톤 | 친구가 알려주는 말투(해요체), 빠른 컷, 큰 자막 |
| 제작 방식 | 얼굴 없음. 상품 사진/직접 촬영 손 컷 + 자막 + TTS 내레이션 |

**분야를 하나로 좁혀 시작한다.** 처음 30개 영상은 한 분야(예: 주방·자취템)에 집중해야 알고리즘이 "어떤 시청자에게 보여줄지"를 빨리 학습한다. 반응이 좋은 분야가 보이면 그 옆 분야(욕실 → 청소 → 정리수납)로 넓힌다.

추천 시작 분야 (단가가 낮고 문제-해결 구조가 선명한 것):

1. 주방 정리·설거지
2. 욕실·청소
3. 자취 수납
4. 차량 용품
5. 반려동물 생활용품

피할 분야: 건강기능식품·의료기기·화장품 효능(표시광고 규제가 까다로움), 고가 가전(구매 전환이 느림), 브랜드 이미지 사용 제한이 많은 명품류.

## 2. 수익 구조

| 경로 | 방식 | 메모 |
|---|---|---|
| **유튜브 쇼핑 제휴 프로그램** | 쇼츠에 쿠팡 상품 **태그**를 달면 화면에 상품명·가격·구매 버튼이 표시되고, 구매 시 수수료 | 한국에서 쿠팡이 첫 제휴사로 시작. 가입 조건(구독자 수, YPP 여부 등)은 바뀔 수 있으니 **YouTube 스튜디오 → 수익 창출 → 쇼핑** 메뉴에서 확인 |
| **쿠팡 파트너스 링크** | 채널 프로필 링크, 커뮤니티, 롱폼 설명란에 링크 | 쇼츠 설명란·댓글의 링크는 눌리지 않을 수 있어 **프로필 링크**로 모으는 방식이 일반적 |
| 유튜브 광고 수익(YPP) | 쇼츠 피드 광고 수익 배분 | 장기 보너스. 초반 목표로 삼지 않는다 |

**초반 운영 방식:** 유튜브 쇼핑 제휴 가입 전에는 "프로필 링크 + 링크 모음 페이지(상품 번호별 정리)"로 운영 → 가입 후에는 영상마다 상품 태그를 다는 방식으로 바꾼다.

> 영상 끝에 "영상 번호 #23"처럼 번호를 붙이고, 프로필 링크 모음 페이지에도 같은 번호로 정리하면 시청자가 상품을 쉽게 찾는다.

## 3. 법적·정책 필수 사항 (반드시 지킬 것)

### 3-1. 경제적 이해관계(광고) 표시 — 공정위 추천·보증 심사지침
- 쿠팡 파트너스·유튜브 쇼핑 수수료를 받는 영상은 **광고**다.
- 표시 문구는 **제목 또는 영상 시작 부분, 그리고 끝부분**에 시청자가 바로 알아볼 수 있게 넣는다. 설명란·고정 댓글에만 적는 것은 부족하다.
- '쿠팡'을 정확히 적는다. "파트너스 활동의 일환으로"만 쓰면 안 된다.
- 표준 문구: `이 영상은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
- 영상 속 짧은 표기: `광고 · 쿠팡 파트너스 활동으로 수수료를 받을 수 있어요`

**이 프로젝트의 기본 세팅 (숏핑 스튜디오가 자동으로 해 줌)**
1. 영상 처음부터 끝까지 상단에 광고 배지 표시
2. 제목 앞 `[광고]`
3. 설명란 첫 줄에 표준 문구
4. 업로드 시 **유료 프로모션 포함** 체크 (유튜브가 영상 초반에 '유료 광고 포함' 라벨을 띄워 줌)

### 3-2. 표현 금지 목록
- 근거 없는 최상급: "최저가", "1위", "무조건", "역대급 최강"
- 직접 쓰지 않은 상품의 체험 표현: "써봤는데", "한 달 후기", "내돈내산"
- 효능 과장: "100% 제거", "평생 쓰는", 의학적 효과
- 가격·평점: 촬영일 기준이라고 밝히고, 업로드 당일 다시 확인

### 3-3. 유튜브 정책
- **반복적·대량생산형 콘텐츠**는 수익 창출이 제한될 수 있다(유튜브는 2025년 '재사용 콘텐츠' 정책을 '진정성 없는 콘텐츠'로 손봤다). 같은 템플릿을 그대로 찍어내지 말고, 영상마다 훅·구성·직접 촬영 컷을 바꾼다.
- AI로 만든 **사실적인** 장면(실제처럼 보이는 사람·장소·사건)이 있으면 업로드 시 **변경되거나 합성된 콘텐츠** 항목을 '예'로 표시한다. 상품 회전샷 같은 명백한 연출은 대체로 해당하지 않지만, 애매하면 표시한다.
- 다른 채널의 영상, 판매 페이지 영상을 통째로 가져다 쓰지 않는다. 상품 사진은 **직접 찍은 것** 또는 **사용이 허락된 이미지**만 쓴다.

## 4. 제작 파이프라인 (영상 1개 = 약 30~40분 목표)

```
① 상품 발굴 (5분)  →  ② 숏핑 스튜디오 입력·대본 (5분)  →  ③ 소재 준비 (10분)
→  ④ 음성(TTS) 만들기 (3분)  →  ⑤ 영상 조립 (10분)  →  ⑥ 업로드·태그 (5분)
```

| 단계 | 하는 일 | 도구 |
|---|---|---|
| ① 상품 발굴 | 쿠팡 카테고리 베스트·골드박스·리뷰 많은 상품 중 **문제-해결이 한 문장으로 설명되는 것** 고르기 | 쿠팡, 쿠팡 파트너스 |
| ② 대본 | 상품 정보 입력 → 훅 3개 중 선택 → 장면표 수정 → SRT 내려받기 | `index.html` (숏핑 스튜디오) |
| ③ 소재 | 직접 산 상품은 손만 나오게 촬영. 아니면 사용 허락된 상품 이미지 + AI 이미지→영상 | 스마트폰, Higgsfield/Kling/Veo |
| ④ 음성 | 내레이션 텍스트를 TTS로 | CapCut 텍스트 음성 변환, 클로바더빙, ElevenLabs 등 |
| ⑤ 조립 | 간단히: 숏핑 스튜디오 '영상 만들기'에 사진+음성 넣고 녹화 / 정교하게: CapCut에 SRT·음성·컷 넣기 | 숏핑 스튜디오, CapCut |
| ⑥ 업로드 | 제목·설명·해시태그 복사, 유료 프로모션 체크, 상품 태그 | YouTube 앱/스튜디오 |

### 상품 선정 체크리스트 (5개 중 4개 이상이면 OK)
- [ ] "○○할 때 불편하죠?" 한 문장으로 문제를 말할 수 있다
- [ ] 화면만 봐도 효과가 보인다 (접힌다, 물이 빠진다, 붙는다 등)
- [ ] 판매가 3만 원 이하 (충동구매 구간)
- [ ] 리뷰 수 수백 개 이상, 평점 4.5 이상
- [ ] 로켓배송 (구매 마찰이 적음)

## 5. 업로드 운영

| 항목 | 기준 |
|---|---|
| 업로드 수 | 처음 4주: 하루 1개 (주 7개). 번아웃이 오면 주 4~5개로 줄여도 **꾸준함이 우선** |
| 길이 | 20~35초가 기본. 15초는 가격충격형 훅에, 45초는 장점이 많은 상품에 |
| 업로드 시간 | 평일 저녁 7~10시, 주말 오전 10시~정오에 올려 보고 스튜디오 통계로 조정 |
| 제목 | 40자 이내, `[광고]` + 훅 + 상품 짧은 이름 + `#shorts` |
| 해시태그 | 3~8개. `#쿠팡추천템 #분야템 #대상필수템` 조합 |
| 시리즈화 | "자취생 주방템 #1~#10"처럼 번호 시리즈 → 재생목록으로 묶기 |

### 주간 루틴 예시
| 요일 | 할 일 |
|---|---|
| 월 | 상품 10개 발굴 → 숏핑 스튜디오 보관함에 저장 (상태: 아이디어) |
| 화~수 | 대본 확정·음성 만들기 7개 (상태: 대본 완료) |
| 목~금 | 영상 조립 7개 (상태: 영상 완료) |
| 매일 | 1개 업로드 (상태: 업로드 완료) |
| 일 | 지난주 통계 보고 잘 된 훅·분야 기록 |

## 6. 성과 지표와 판단 기준

| 지표 | 어디서 보나 | 좋은 신호 | 대응 |
|---|---|---|---|
| 조회 vs 넘김 비율(시청 선택 비율) | 스튜디오 → 쇼츠 분석 | 70% 이상 | 낮으면 **첫 2초 훅·첫 화면** 교체 |
| 평균 시청 비율 | 스튜디오 | 80% 이상(30초 기준) | 낮으면 중간 장면을 줄이고 템포 올리기 |
| 상품 클릭/주문 | 스튜디오 쇼핑 탭, 쿠팡 파트너스 리포트 | 조회 1천당 클릭 수 증가 추세 | 가격·CTA 장면을 앞으로 당겨 보기 |
| 구독 전환 | 스튜디오 | 영상당 구독 꾸준히 발생 | 시리즈화, 마지막 장면 구독 유도 |

**4주 후 판단**: 28개 중 상위 5개 영상의 공통점(분야·훅 스타일·길이·가격대)을 뽑아 다음 4주 기획의 70%를 그 방향으로, 30%는 새 실험으로 채운다.
