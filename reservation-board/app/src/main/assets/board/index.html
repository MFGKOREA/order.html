설정 알림판으로

오늘 들어온 예약

설정

이 태블릿에서 어떤 앱의 예약 알림을 모을지 정해요. 바꾼 내용은 바로 저장돼요.

예약 받기

알림 접근 권한

예약 알림판이 네이버·자사앱의 알림을 읽으려면 필요해요. 두 앱은 그대로 두고, 태블릿에 뜬 알림만 읽어요.

목록에서 ‘예약 알림판’을 켜 주세요. 스위치가 회색으로 막혀 있으면 태블릿 설정 → 애플리케이션 → 예약 알림판 → 오른쪽 위 ⋮ → ‘제한된 설정 허용’을 누른 뒤 다시 켜요.

알림 방식

알림음

새 예약이 오면 알람 볼륨으로 울려요. 홀이 시끄러워도 들리게요.

음성 안내

알림음 뒤에 “네이버 새 예약 알림”처럼 어디서 온 예약인지 말해 줘요.

글자 크기

카운터 건너편에서도 읽히게 키울 수 있어요.

관리

테스트 알림

소리와 화면 깜빡임이 잘 나오는지 가짜 예약 한 건으로 확인해요. 누를 때마다 출처가 번갈아 바뀌어요.

하루 종일 켜 두기

배터리 최적화에서 예약 알림판을 ‘제한 없음’으로 바꿔야 오래 켜 둬도 알림을 놓치지 않아요. 태블릿은 충전기에 꽂아 두세요.

기록 지우기

알림판의 기록만 지워요. 네이버·자사앱의 실제 예약은 그대로예요. 기록은 일주일이 지나면 저절로 지워져요.

예약 알림을 보내는 앱을 골라요. 최근에 알림을 보낸 앱이 위에 있어요.
