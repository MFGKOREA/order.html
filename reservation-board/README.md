# 예약 알림판

태블릿 한 대에서 **네이버 예약**과 **자사앱 예약** 알림을 한 화면에 모아 보는 안드로이드 앱입니다.
두 앱이 태블릿에 띄우는 예약 알림을 읽어서 시간순으로 보여 주고, 새 예약이 오면 소리·음성·화면 깜빡임으로 알려 줍니다.

- 보기 전용입니다. 예약 확정·취소는 항목을 눌러 원래 앱에서 처리합니다.
- 네이버나 외주 업체의 연동(API)이 필요 없습니다.
- 알림 내용은 태블릿 밖으로 나가지 않고, 기록은 일주일 뒤 자동으로 지워집니다.

## 설치 (처음 한 번)

1. 태블릿에 **네이버 스마트플레이스 앱**과 **자사앱**을 둘 다 설치하고 로그인합니다. 두 앱 모두 알림이 켜져 있어야 합니다.
2. `reservation-board.apk` 파일을 태블릿으로 옮겨서(카카오톡 나에게 보내기, 구글 드라이브 등) 엽니다.
   "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켭니다.
3. **예약 알림판**을 열고 빨간 안내줄을 눌러 **알림 접근 권한**을 켭니다.
   - 스위치가 회색으로 막혀 있으면: 태블릿 **설정 → 애플리케이션 → 예약 알림판 → 오른쪽 위 ⋮ → 제한된 설정 허용**을 누른 뒤 다시 켭니다.
4. 오른쪽 위 **설정 → 예약 출처**에서 네이버 쪽 **앱 고르기**로 네이버 앱(예: 스마트플레이스)을, 자사앱 쪽에서 자사앱을 고릅니다.
   - 어느 앱인지 헷갈리면 각 앱에서 알림이 한 번 온 뒤 목록을 열어 보세요. 최근에 알림을 보낸 앱이 맨 위에 **"최근 알림"** 표시와 함께 나옵니다.
5. 리뷰·광고 알림까지 섞여 보이면 키워드에 `예약`을 넣습니다.
6. **설정 → 배터리 최적화 설정 열기**에서 예약 알림판을 **제한 없음**으로 바꿉니다. 태블릿은 충전기에 꽂아 두세요.
7. **설정 → 테스트 알림 보내기**로 소리와 화면 깜빡임이 나오는지 확인합니다.

## 화면

- 맨 위 **● 수신 중**이 초록색이면 정상입니다. 빨간색이면 알림 접근 권한을 확인하세요.
- 제목 아래 한 줄이 지금 할 일을 알려 줍니다: "확인 안 한 새 예약 2건이 있어요".
- **오늘 수신 흐름**은 오늘 받은 알림을 시간축 위 점으로 보여 줍니다. 몰리는 시간대가 한눈에 보이고, 점을 누르면 그 예약으로 이동합니다.
- **전체 / 네이버 / 자사앱** 탭에는 오늘 들어온 건수가 나오고, 누르면 그 출처만 보입니다.
- 새 예약에는 **새 예약** 표시와 **확인** 버튼이 붙고, 확인한 예약은 회색으로 물러나서 새 예약이 멀리서도 먼저 보입니다.
- 항목을 누르면 네이버 앱 또는 자사앱의 해당 예약 화면이 열립니다.
- 시간 옆 "수신"은 알림을 받은 시각입니다. 예약 시각은 본문에 나옵니다.

## 한계

- 알림에 나온 내용만 보입니다. 알림을 끄거나 앱에서 로그아웃하면 알림판에도 나오지 않습니다.
- 아이패드에서는 동작하지 않습니다(다른 앱 알림을 읽을 수 없음).

## 개발

- 알림 수신·저장·소리: 순수 Java, 외부 라이브러리 없음. 최소 안드로이드 8.0.
- 화면: `app/src/main/assets/board/` 의 HTML·CSS·JS를 앱 안의 WebView로 띄웁니다. 글꼴은 Pretendard(OFL)를 넣어 두었습니다.
  `index.html` 을 브라우저로 바로 열면 `mock.js` 의 견본 데이터로 미리 볼 수 있습니다.

```
./gradlew assembleRelease        # app/build/outputs/apk/release/app-release.apk
./gradlew testReleaseUnitTest    # 알림 수신 로직 테스트 (Robolectric)
```
