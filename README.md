# 유튜브 쿠팡 쇼핑 숏폼 프로젝트

얼굴 없이 만드는 쿠팡 상품 소개 유튜브 쇼츠 채널을 위한 도구와 기획 문서입니다.

## 쓰는 법

1. 채팅에 쿠팡 링크를 보냅니다. 쿠팡 앱의 **공유 → 복사** 문구를 그대로 붙여넣으면 상품명까지 들어가서 더 정확해요.
2. Claude가 `index.html`(숏핑 스튜디오)에 그 상품의 쇼츠 패키지를 추가합니다: 대본, 제목 3개, 설명란, 해시태그, 고정 댓글, 자막.
3. 페이지에서 **사진 넣기 → 영상 저장 → 문구 복사** 후 업로드할 때 **유료 프로모션 포함**을 체크합니다.

영상에는 처음부터 끝까지 광고 배지가 들어가고, 설명란 첫 줄과 제목 앞 `[광고]`도 자동으로 들어갑니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 숏핑 스튜디오. 상품별 쇼츠 패키지 목록 (발주 앱 크림 테마) |
| `studio.html` | 예전 상세 버전. 상품 정보를 직접 입력해서 쓰는 도구 |
| `docs/01-채널-기획서.md` | 채널 콘셉트, 수익 구조, 광고 표시 의무, 운영 계획 |
| `docs/02-쇼츠-대본-템플릿.md` | 30초 구조, 훅 공식, 예시 대본 |
| `docs/03-AI-영상-제작가이드.md` | 영상 제작 방법 세 가지와 주의점 |
