# 유튜브 쿠팡 쇼핑 숏폼 프로젝트

얼굴 없이 만드는 쿠팡 상품 소개 유튜브 쇼츠 채널을 위한 도구와 기획 문서입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | **숏핑 스튜디오**: 상품 정보를 입력하면 대본, 자막(SRT), 제목·설명·해시태그, 광고 표기, AI 영상 프롬프트를 만들고 9:16 영상까지 녹화하는 단일 웹페이지 |
| `docs/01-채널-기획서.md` | 채널 콘셉트, 수익 구조, 광고 표시 의무, 제작 파이프라인, 운영·지표, 첫 달 로드맵 |
| `docs/02-쇼츠-대본-템플릿.md` | 30초 구조, 훅 공식 15개, 예시 대본 5개 |
| `docs/03-AI-영상-제작가이드.md` | 바로 녹화 / CapCut / AI 이미지→영상 세 가지 제작 방법과 주의점 |

## 숏핑 스튜디오 쓰는 법

1. `index.html`을 크롬이나 엣지로 엽니다. 설치할 것이 없습니다.
2. 상품명, 고민, 장점(한 줄에 하나), 가격, 파트너스 링크를 입력합니다.
3. **대본·자막** 탭에서 훅 3개 중 하나를 고르고, 표 안 문장을 눌러 고칩니다.
4. **업로드 문구** 탭에서 제목·설명·해시태그·고정 댓글을 복사합니다.
5. **영상 만들기** 탭에서 상품 사진과 (선택) TTS 음성을 올리고 녹화합니다.
6. **보관함**에 저장해 상품별 제작 상태(아이디어 → 업로드 완료)를 관리합니다. 데이터는 이 브라우저에만 저장됩니다.

만든 영상에는 처음부터 끝까지 `광고 · 쿠팡 파트너스 활동으로 수수료를 받을 수 있어요` 배지가 들어가고,
설명란 첫 줄과 제목 앞 `[광고]`도 기본으로 들어갑니다. 업로드할 때 **유료 프로모션 포함**도 꼭 체크하세요.
