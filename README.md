# LongCraft — PhotoCraft · EffectCraft

사진과 영상으로 **롱폼 영상**을 만드는 브라우저 편집기입니다. 설치 없이 `index.html` 하나로 동작하고, 파일은 서버로 올라가지 않습니다.

## 두 개의 탭

**PhotoCraft (포토크래프트)** — 구성
- 사진·영상 여러 개 추가 (드래그 앤 드롭), 타임라인에서 드래그로 순서 변경, 이름순·날짜순·섞기
- 클립별 길이 / 영상 시작 지점·사용 길이·소리
- 켄번즈 모션 (자동, 줌 인·아웃, 상하좌우 팬) + 강도
- 화면 맞춤: 꽉 채우기 / 전체 + 블러 배경 (세로 사진 자동)
- 보정: 밝기·대비·채도·색온도 (모든 클립에 일괄 적용 가능)
- 자막 3종: 하단 자막 · 챕터 제목 · 로워서드
- 전환 8종: 컷, 디졸브, 블랙 페이드, 화이트 플래시, 슬라이드, 줌, 와이프, 블러

**EffectCraft (이펙트크래프트)** — 효과
- 룩 9종 (시네마틱 틸&오렌지, 웜 필름, 쿨 나이트, 누아르, 빈티지, 비비드, 드리미, 블루 모노) + 강도
- 필름 그레인, 비네팅, 라이트 릭, 색수차, 글리치 버스트, 핸드헬드 흔들림
- 시네마 바(2.39:1 등), 시작/끝 페이드, 진행 바, 포인트 컬러
- 인트로·아웃트로 타이틀, 자막 글꼴(프리텐다드·노토 세리프·블랙한산스·나눔 펜)
- 워터마크·채널명
- 배경음악: 볼륨, 페이드, 반복, 영상 소리 나올 때 자동으로 줄이기(덕킹)

## 내보내기

- 720p / 1080p / 1440p, 24·30·60fps, 화질 3단계
- MP4 (H.264 + AAC) — 브라우저가 지원하면 자동 선택, 아니면 WebM (VP9 + Opus)
- 실시간보다 빠른 WebCodecs 인코딩 ([Mediabunny](https://mediabunny.dev))
- **파일로 바로 저장** 옵션: 긴 영상을 메모리에 쌓지 않고 디스크로 바로 기록 (Chrome·Edge)
- 유튜브 챕터 타임스탬프 자동 생성 ('챕터 제목' 자막 기준), 하단 자막 SRT 다운로드

## 사용법

1. `index.html`을 Chrome 또는 Edge로 엽니다 (GitHub Pages로 배포해도 됩니다).
2. 사진·영상을 넣거나 **데모 사진으로 시작**을 누릅니다.
3. PhotoCraft에서 순서·모션·자막을, EffectCraft에서 룩·질감·타이틀·음악을 정합니다.
4. **내보내기**를 누릅니다.

단축키: `Space` 재생/정지 · `←/→` 1초 이동 (`Shift` 5초) · `Home/End` · `Delete` 선택 클립 삭제

## 참고

- 권장 브라우저: 최신 Chrome / Edge (데스크톱). Firefox·Safari는 일부 필터 효과가 다르게 보일 수 있습니다.
- HEIC 사진은 브라우저가 읽지 못하므로 JPG로 변환 후 넣어 주세요.
- 인코딩 라이브러리와 웹폰트는 CDN(jsDelivr, Google Fonts)에서 불러오므로 내보내기에는 인터넷 연결이 필요합니다.
