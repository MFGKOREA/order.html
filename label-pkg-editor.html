라벨 패키지 열기

프린터에 설치했던 .pkg 파일을 그대로 넣습니다. 파일은 이 화면 안에서만 처리되고 어디에도 보내지 않습니다.

.pkg 파일을 끌어다 놓거나 선택 MFG_KOREA_LIST_날짜.pkg

저장하지 않은 수정이 있습니다

    새 패키지 저장

    품목 테이블만 바꿔 넣은 .pkg를 만듭니다.

    1. 프린터의 기존 .pkg와 설정을 백업해 둡니다.
    2. 새 .pkg를 USB 메모리에 넣어 프린터에서 설치하거나 SATO All-In-One Tool로 보냅니다.
    3. 바뀐 품목 한두 개를 골라 라벨을 시험 출력해 확인합니다.

    그대로 두는 것 화면, 라벨 디자인, 폰트, 로고, 스크립트. 이 도구는 품목 테이블 파일 하나만 바꿉니다.
