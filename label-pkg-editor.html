MFG 라벨 패키지 편집기

SATO FX3-LX 라벨프린터용 .pkg 파일을 열어 품목 목록을 고치고 새 .pkg로 저장합니다.

라벨 패키지(.pkg)를 여기에 끌어다 놓거나 선택하세요

프린터에 설치했던 .pkg 파일을 그대로 넣으면 됩니다. 파일은 이 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

열 설명

프린터 화면의 버튼 이름과 같아야 합니다. 기존 값을 쓰면 목록에서 고를 수 있습니다. 새 값을 넣으면 카테고리 버튼이 바뀌지 않으므로 화면에 안 나올 수 있습니다.
일수
보관 일수입니다. 0은 당일, T는 시간 입력형 라벨입니다. 시간 열과 둘 중 하나만 채웁니다.
시간
보관 시간(시간 단위)입니다. 시간형 품목(ⓗ 표시)에 씁니다.
시작일 / 종료일 / OPEN
기존 품목에 적힌 값을 그대로 따라 쓰세요. 비워 두면 빈 값으로 저장됩니다.
새 패키지 저장

수정한 목록을 넣은 .pkg 만들기

저장 후 프린터에 올리는 순서

  1. 프린터의 현재 설정과 기존 .pkg 파일을 백업해 둡니다.
  2. 새 .pkg를 USB 메모리에 넣어 프린터에서 설치하거나, SATO All-In-One Tool로 전송합니다.
  3. 바뀐 품목 한두 개를 골라 라벨을 시험 출력해 날짜와 품목명을 확인합니다.
